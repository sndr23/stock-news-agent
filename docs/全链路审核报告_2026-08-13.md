## 三、新发现问题（实测证据）

### P0 — `tech_override` 绕过 LLM 否决，研报/观点类误推的主通道

**位置**：`run_once` 5c，`tech_override`（scripts/real_time_push.py 第1830-1850行）。

**机制**：5c 在强档门槛后执行（direction 必为 bullish/bearish），因此 `score>=5 or strong` 恒为真，`tech_override` 退化为"scope=sector 且含国内科技词"或"scope=stock 且龙头且含国内科技词"。只要满足，**即使 LLM 判 `push=false`，也强制放行推送**（第1848-1850行 `elif tech_override: pass_round=True`）。

**实测**（用 LLM 判 push=false 的研报/观点类标题）：

| 标题（研报/观点类） | LLM push | tech_override | 最终 |
|---|---|---|---|
| 产业资本加速投入 机构称物理AI市场空间将迈向星辰大海 | false | True | **推送（误推）** |
| AI服务器液冷投资向零部件纵深传导 液冷产业链迎订单验证关键窗口 | false | True | **推送（误推）** |
| 多家上市公司加码液冷散热业务 | false | False（"液冷散热"非 OVERSEAS_TECH 词） | 不推 |

**影响**：今日 19 推中"机构称物理AI""液冷投资传导"等研报/观点类正是这条路径进来的。今天 prompt 新增的"券商研报/机构观点/主题性分析不推"**会被 tech_override 抵消**——LLM 按 prompt 判 push=false 后，tech_override 又放行。

**修复建议**：`tech_override` 增加"研报/观点/主题"排除守卫——标题含 `机构称/研报/认为/预计/点评/有望受益/市场空间/传导/开启XX潮` 等词时不放行；或限定 tech_override 只放行"有具体事件佐证（金额/订单/政策动作/公司公告）"的科技消息。

### P1 — `_topic_saturated` 与 `_is_same_event` 的板块/实体一致性

**位置**：`_topic_saturated`（scripts/real_time_push.py 第687-690行）。

**机制**：饱和判断用精确交集 `secs & psecs` / `ents & pents`；而合并判断 `_is_same_event` 已改用 `_sectors_overlap`（子串包含）+ 归一化实体。两者口径不一致。

**实测**：
- 实体空场景：新条目 sectors=`["AI算力"]`，已推 5 条 sectors=`["AI","算力"]`。`_sectors_overlap` 判同板块（{"AI","算力"}），但 `_topic_saturated` 精确交集为空 → **返回 False（饱和漏判）**，同题材实际可推超 5 条。
- 实体别名：新实体"摩根士丹利"（归一化后）vs 旧 pushed_events 数据"大摩"（未归一化）→ 精确交集空 → 饱和漏判（过渡期问题，随时间自愈）。

**修复建议**：`_topic_saturated` 板块重叠改用 `_sectors_overlap`，实体重叠用归一化后交集。

### P2 — 预筛直通词增多，候选量 17.4%

**实测**：用新代码重跑今日 1290 条 seen 标题，**224 条（17.4%）会进 LLM 判定**（218 直通 + 6 过门槛），远超单轮上限 40。分轮运行时不会一次性触达 40，但行情活跃时段单轮新增多 → 溢出挂起（pending）增加。

**评估**：有 pending 挂起保护（不丢失），但 LLM 调用成本与推送延迟上升。龙头主体词（腾讯/阿里/苹果/微软/英伟达等）较宽泛，直通进来的日常/行情消息需 LLM 再否决，精度待观察。属"防漏推 vs 控成本"的权衡，当前偏向防漏推（符合用户"重大不能漏"口径），暂可接受，但建议监控溢出率。
