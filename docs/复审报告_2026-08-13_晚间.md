## 六、残余问题（按优先级）

### P2-1 残余 — `tech_override` 排除词表不完整（误推）

**位置**：`_TECH_OVERRIDE_VIEW_WORDS`（scripts/real_time_push.py 第542行）。

**机制**：排除词表含"机构称/研报/点评/观点/市场空间/传导"等，但**缺分析师警告措辞（警告/示警/预计/目标价/评级）与泛板块无事件佐证措辞（加码X业务）**。这类标题只要 scope=sector + 含科技词 + 强档，LLM 判 `push=false` 仍被强制放行。

**实测**（完整 run_once 判定顺序：强档→噪声→阈值/tech_override）：

| 标题 | noise | tech_override | 最终 |
|---|---|---|---|
| 多家上市公司加码液冷散热业务（#40） | '' | True | **仍推送** |
| AI不缺需求缺算力 摩根士丹利警告供应瓶颈（#42） | '' | True | **仍推送** |
| 企业AI应用步伐加快 大摩示警算力严重不足（#54） | '' | True | **仍推送** |

**影响**：14:21 审核标记的 #1（液冷散热误推）与 #14（大摩误推）在**当前代码下仍会复现**——tech_override 修复只堵住了"机构称/传导"，没堵住"警告/示警/加码"。

**修复建议**（二选一，倾向前者）：
1. `_TECH_OVERRIDE_VIEW_WORDS` 补 `"警告","示警","预计","目标价","评级","加码"`（注意"警告"可能误伤央行/交易所风险警示，建议同时要求命中券商实体 或 保持宽松让 LLM 复核）；
2. 或对 `scope=sector 且 entities 为空 且无金额/订单/政策动作` 的科技消息不放行（此前的原始建议，但会轻微提高漏推风险，与"防漏推"口径冲突）。
