# 创业板仓位择时系统说明（2026-08-28 更新）

> 服务对象：重仓中际旭创（300308）的场外基金手动操作辅助，每日 14:45 推送仓位信号。
> 本文件记录系统架构、因子体系、本次（08-22）新增能力与验证结论。

---

## 一、系统定位

**单资产择时**：预测创业板指（399006）未来方向，输出目标仓位（0/60/90/100%），供用户 15:00 截单前手动执行场外基金申赎。

**关键前提（08-22 确认）**：用户持有场外基金，该基金重仓中际旭创（300308）——旭创作为创业板**科技龙头情绪标的**（近半年与创业板日收益相关 0.83，全样本 0.59，beta≈2.0）。因此系统采用**创业板+旭创双确认**架构：创业板指数为主信号（基金净值分散，与指数相关性更高），中际旭创作为科技龙头情绪领先指标做方向二次确认。

## 二、三层打分架构

```
核心层（可回测，权重100%基准，v5 权重 2026-08-28 STR-03 合入）
  趋势0.50 + 量价0.20 + 波动0.20 + 估值0.00 + 落袋0.10
  全部由 399006 日线（close+amount）计算，12 年历史可回测验证
  （v4 旧权重 趋势0.35/估值0.10/落袋0.15：估值维打分关闭后 0.10 为死权重，
   曾把核心分量纲压缩 10%；提权趋势的 OOS 证据见 策略缺陷实验报告_20260828 方案 C）

修正层（不可回测的当日实时数据，有界 ±0.30）
  贴水(±0.06) + 资金(±0.05) + 情绪(±0.04) + 资讯(±0.06)
  + 缠论结构(±0.08) + 旭创双确认(±0.10)
  合计封顶 ±0.30——中性市场最多被推到六成档，永远到不了满仓档

硬风控（最高优先级，覆盖一切）
  回撤/波动分位/risk_off/深贴水/盘中急跌/缠论顶背驰/外盘辅助确认
  + ERP估值极端滤波（便宜度分位<0.10 封顶6成，2026-08-22 新增）→ 仓位封顶
```

档位状态机（0/60/90/100%，收益优先中枢上移）：升档需连续两日确认，降档当日生效（非对称：进场慢、出场快）。

## 三、因子体系与验门纪律

### 核心层 9 个注册因子（其中 8 个有效参与打分）
| 维度 | 因子 | 说明 |
|---|---|---|
| 趋势 | trend_ma20_60 / trend_momentum_60 | 双均线状态 + 60日时序动量 |
| 量价 | volprice_quadrant / volprice_amihud | 量能分位四象限 + 非流动性 |
| 波动 | vol_regime / vol_term | 20日年化vol分位 + 期限结构 |
| 估值 | value_erp | 股债性价比（生产不注入，负贡献关闭） |
| 落袋 | pullback_52w / dd60 | 52周高点接近度 + 60日回撤 |

### 验门纪律（本项目核心约束）
任何因子进核心层必须：**|IC|≥0.05 且样本≥10**（影子 IC 验门），否则关闭。

### 已验证关闭的因子（08-22 结论）
| 因子 | 结论 | 原因 |
|---|---|---|
| 估值（PE/ERP） | 打分关闭；极贵时独立封顶6成 | 估值打分样本外负贡献，极端滤波仅作为保守风控 |
| 业绩预告事件 | 关闭 | 因子退化为常数，IC=0 |
| 两融杠杆 | 关闭 | IC 不达标，避险价值弱 |
| 外盘打分（SOX/NDX/INX） | 关闭 | 全样本 IC<0.05，近期负相关为短暂 regime |
| 卫星图像 / ML 复合因子 | 不适用 | 单资产择时架构错配，无法回测验证 |

## 四、本次新增能力（08-22）

### 1. 外盘硬风控辅助确认
- **背景**：用户反馈"最近市场跟纳指/韩指"。数据验证：SOX 费半近 6 月 IC=-0.113（显著），但全样本 12 年仅 -0.004——**近期负相关是短暂 regime，不是稳定因子**。KOSPI 免费数据源全被墙（东财 proxy 挡、雅虎 timeout、新浪无接口）。
- **实现**：`overseas.overnight_drop()` 计算 t-1 隔夜 SOX/纳指/标普最差跌幅（无前视）。数据链为
  `akshare` 新浪封装 → Yahoo Chart → Stooq CSV；三个指数独立回退并检查末根新鲜度。
  Yahoo/Stooq 若限流、被浏览器验证或返回过期数据，序列直接缺失并降级为 0，不把 HTTP 200
  或旧缓存当成有效行情。
- **触发逻辑**（`chinext_factors.defensive_state`）：
  - 外围 ≤-3% + 盘中 ≤-1.5% → 封顶 3 成（同源确认）
  - 外围 ≤-3% + 盘中 ≤-1.0% → 封顶 6 成
  - **不独立触发**——避免近期负相关 regime 结束后的反向押注
- **验证**：6 边界用例全过；今日 dry-run 外围无大幅下杀，未触发（符合预期）。

### 2. 中际旭创双确认（核心新增）
- **背景**：用户持有基金重仓中际旭创（300308），旭创作为创业板科技龙头**情绪领先指标**。数据验证：价格相关 0.53、日收益相关 0.59（全样本）/ 0.83（近半年）、beta≈2.0；领先性弱（旭创→次日创业板 +0.05，创业板→次日旭创 +0.05，几乎对称）——**它的价值在同向确认与背离预警，而非预测**。
- **数据层**：`data.load_stock_sina()` 按新浪 → 腾讯 → 东财顺序加载个股历史，三者均为免费接口；各源结果按末根交易日校验，全部失败或过期时该确认维度降级。
- **逻辑层**：`chinext_timing.stock_confirm()` 纯函数——指数信号 × 个股趋势/动量一致性：
  - 指数看多但个股走弱（个股先于指数走弱）→ 降档确认 **-0.10**
  - 指数看空但个股企稳走强 → 温和升档 **+0.08**
  - 同向 → 中性（主信号已覆盖）
- **实况验证（08-22）**：创业板指数趋势 +0.60（看多），但中际旭创方向 -0.39（走弱）→ 触发"指数多/情绪标的弱，降档确认"，综合分 -0.09→-0.19，**避免在科技龙头情绪走弱时按指数信号进场**。
- **旭创侧回测**：同因子/同档位线，夏普 0.99 / 卡玛 0.56（优于指数 0.68/0.28），回撤 -58.8%（佐证 2 倍 beta 需谨慎）。⚠️ 绝对收益 +2620% 不可当真（12 年持有 +225 倍的幸存者偏差）。

## 六、数据源与降级策略

| 数据 | 源 | 降级 |
|---|---|---|
| 创业板指日线 | 新浪全量（免费直连） | 东财/腾讯免费增量链回退 |
| 中际旭创日线 | 新浪个股（绕代理）→ 腾讯日K → 东财历史日线 | 各源过期/失败时继续回退；全部缺失则跳过双确认 |
| 外盘（SOX/NDX/INX） | akshare 新浪封装 | Yahoo Chart → Stooq CSV；仍失败则该序列降级为 0 |
| 估值（创业板50 PE） | 乐咕乐股 | 缺源 value_erp=0 |
| 盘中实时 | 腾讯 | 降级为 0 |

增强维度源失败时独立降级；核心 399006 历史为空或不足 62 根时停止推送，**不生成伪信号**。

估值只接受乐咕创业板50 TTM PE 的正数记录，兼容中文和英文 TTM 字段；日期对齐前的
缺失值保持中性，不以 0 PE 参与滚动分位。过期缓存或过期实时结果不进入当日增强维度。
