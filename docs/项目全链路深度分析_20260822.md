## 一、结论先行

1. **本质是两套系统，不是一个"量化程序"**：一套「事件驱动资讯推送」（LLM 判定 + 三层去重 + 微信快讯），一套「创业板单资产择时」（9 个注册因子、8 个有效因子打分 + 仓位状态机 + 缠论 + 旭创双确认）。真正的量化内核在择时系统 + `factor_collector` 因子采集 + `signal_backtest` IC 验证；资讯线是**软信号/信息流系统**。
2. **最强项是工程容错，而非 alpha**：事件级指纹 + 同事件签名 13 分支（每个分支带实证事故注释）、Gist fail-stop 状态机、漏推保护链（挂起重试/候选溢出 pending/300s 熔断/心跳告警）、CI 测试门禁——这套工程纪律显著优于同类个人项目。
3. **最需审慎的是回测数字**：当前严格信息集回测为策略 **+105.3%**、年化 **+6.2%**、夏普 **0.46**、最大回撤 **-42.1%**，买入持有 **+170.1%**、最大回撤 **-69.7%**；首轮 walk-forward OOS 为策略 **+64.6%**、年化 **+5.7%**、夏普 **0.41**、最大回撤 **-27.8%**，买入持有 **+111.2%**。单次换仓成本 0.3% 后 OOS 为 **+19.0%**、年化 **+2.0%**、夏普 **0.20**、最大回撤 **-38.3%**。策略主要体现回撤改善，尚无跑赢买入持有或存在稳定 alpha 的证据；旧口径仅作历史对照。
4. **信任基石仍空缺**：`signal_backtest` 是设计中的可信度底座，但 `dir` 字段 2026-08-19 才上线，当前 64 条已推事件可评估 0 条（冷启动）——资讯信号"是否有效"暂时无法量化。
5. **当前工程风险集中在状态并发、外部调度与免费源可用性**：Gist 读-改-写仍非原子（高）；外部定时服务与 Actions 最近实际运行记录尚未核验（中）；数据源全部为免费 HTTP 抓取，东财、Yahoo/Stooq 已有反爬或限流实证（中低）。基金轮动入口、`capped` 语义和修正层分项封顶问题已修复，不再列为当前故障。

## 三、子系统深析

### 3.1 资讯实时推送管线（软信号系统）

**数据源（8 新闻 + 2 信号）**：东财/新浪/同花顺/富途（akshare 聚合）、财联社（直连 cls.cn）、华尔街见闻（直连 api-one-wscn）、金十（直连 flash-api + x-app 头）、Google News RSS（5 组查询词，需代理）；信号源=龙虎榜（机构净买≥3000万 top15）+ 业绩预告（幅度>100% 或 <-50% top20）。反爬：三冗余 + UA/Referer 定制 + 元组超时 + `socket.setdefaulttimeout(20)` 兜底。

**处理链**（`run_once`，10 步）：
```
0 状态加载(fail-stop) → 1 抓取(三层去重: URL→标题→SimHash) → 2 增量(指纹48h)
→ 3 预筛(≥0.55/直通信号词，候选>40 三级排序截断，溢出挂pending)
→ 4 LLM判定(6档方向+0-10分+3档置信+3级范围，idx对齐，300s熔断，未回显挂起)
→ 5a 同事件分组(13分支) → 5b 选代表(push优先→score→预筛分)
→ 5c 强档门槛(仅bullish/bearish) → 噪声硬过滤 → risk_off降级 → 跨轮拦截
→ 同题材饱和(默认5/24h) → 叙事链矛盾附注 → 推送(红涨绿跌)
未达标/未判定 → 静默记指纹 或 挂起下轮重试(≤3轮，高信号永不放弃)
```

**去重体系（全项目最扎实的部分）**：
- 三层近似去重：URL 规范化 → 标题精确 → SimHash（32bit MD5 3-gram，海明距离≤3）；
- 事件级指纹 `_news_fingerprint`：命中信号词用 `date|sig+ev+st/标题前6字`（不掺数字防"1700亿/一千七百亿"分叉），`title_head[:6]` 防不同公司同金额指纹碰撞；
- 同事件合并 `_is_same_event`（L803-962，13 个 return True 分支）：共享事件组+实体重叠、金额交集、LCS≥5、时段组+市场域、指数词+时段、sectors+行情措辞、宏观数据词、央行实体+政策词+方向守卫、字符集 Jaccard≥0.6、实体+事件短语锚+金额守卫、sectors 子串≥2+LCS≥2、同锚放宽 LCS 占比 0.35/0.55、子序列兜底（存储ETF vs 内存ETF）。每分支带实证事故注释（恩智浦三推/索尼×台积电三推/日本央行三推/纳指三推等）。

**LLM 判定**：系统提示 8 类必推+明确不推清单；idx 原样回显优先、标题兜底；解析三级容错（代码块→平衡括号→`_repair_json` 中文标点转义→正则抢救）；`_normalize_direction` 别名表（看涨/利多/强利好→bullish 等，key 按长度降序）+ 规则兜底 `predict_direction_by_rules`（否定词窗口奇偶取反 + 反向前缀修正）。

**推送**：PushPlus（免费 200 条/天，4800 字截断）/ 企业微信（3800 字节截断，确定性错误码不重试）/ WxPusher（已实现未接入），双后端故障转移；红涨绿跌 + emoji（bullish🔴/bearish🟢）。

**状态层**：Gist `real_time_state.json`（读 3 次重试 + `?ts=` 绕 CDN；损坏即 fail-stop 拒绝空状态运行——曾冲掉 4759 条 seen）；seen 上限 3000 / pending 200 / pushed_events 300，48h 滚动清理；`_merge_state` 写前合并（seen pushed 优先、pending retry 取大、pushed_events 按 `_event_sig_key` 并集）。

### 3.2 量化因子采集流（factor_collector.py 2589 行）

**6 正式维度**（参与方向合成）：

| 维度 | 逻辑 | 异动阈值 |
|---|---|---|
| 对冲 | IC/IM 贴水 3 日单调收敛=+1/走扩=-1 | 创 20 日最深（warning） |
| 风险 | risk_state 映射 0/-1 | — |
| 量价 | 核心指数量比≥1.5 突破=+1/破位=-1 | 量比≥1.5 |
| 汇率 | 美元/日元 \|涨跌\|≥1.5% 急升=-1/急贬=+1 | ±1.5% |
| 波动率 | P3-3 20日已实现波动率≥80 分位=-1 | ≥80 分位 |
| 宽度 | P3-2 普跌≥80%=-1/普涨≤20%=+1 | 普跌≥80% |

**影子维度**（进 direction_history 供 IC 回测，不参与合成）：P7 流动性（GC007≥3%）、P8 期权 PCR（≥1.3/≤0.55）、P12 KOSPI±2%、日线衍生 5 维（动量20日/反转5日/均线结构/量价配合/跳空）、分钟级 2 维。

**方向合成**：`_direction_analysis` 等权均值或 **IC 加权**（`Σ(w·s)/Σw`，n≥20 启用，动态 import signal_backtest 的 `compute_factor_ic`，复用本轮上证 K 线零请求）；阈值 ±0.5 判偏多/偏空/中性；P5-1 门控（高波→利空维×1.5、普跌+日元急升→汇率/宽度×1.5）。

**risk_state**：任一 warning → `"risk_off"`（无时效衰减，偏简）。消费方：real_time_push `_risk_off_downgrade`（risk_off 时科技 bullish 且无硬事件佐证→降级不推）、news_link L3 宏观 overlay、chinext_timing 修正层。**2026-08-22 起因子线停推但持续采集**（realtime-factor.yml `--collect`），保 snapshot 供择时；健康度告警仍可发送。

### 3.3 创业板仓位择时（真正的量化内核，2026-08-22 核心）

**三层架构**：
- **核心层**（可回测，权重 100% 基准）：9 个注册因子五维 = 趋势 0.35 + 量价 0.20 + 波动 0.20 + 估值 0.10 + 落袋 0.15；`value_erp` 当前关闭，实际 8 个因子参与核心打分。因子：`trend_ma20_60` / `trend_momentum_60` / `volprice_quadrant` / `volprice_amihud` / `vol_regime` / `vol_term` / `value_erp` / `pullback_52w` / `dd60`；全部由 399006 日线计算，12 年可回测。
- **修正层**（当日实时数据，总 clamp ±0.30）：贴水 + 资金 + 情绪 + 资讯 + 缠论（±0.08）+ 旭创双确认（±0.10）。资金、情绪、资讯已分别落实 ±0.05、±0.04、±0.06 分项上限，末尾仍保留总 clamp。
- **硬风控**（最高优先级）：回撤≤-12% 封顶 3 成（-8%→6 成）、vol_pctile≥95→6 成、risk_off→3 成、贴水≤-15%→6 成、盘中≤-2.5%→3 成、缠论顶背驰→6 成、**外盘辅助确认**（SOX/NDX/INX 隔夜≤-3% + 盘中≤-1.5%→3 成 / ≤-1.0%→6 成，不独立触发）、**ERP 估值极端滤波**（便宜度<0.10=500 日顶部 10%→封顶 6 成，2026-08-22 上线）。

**档位状态机**：TIERS=(≥0.40→100%, ≥-0.15→90%, ≥-0.30→60%, 更低→0)；升档需连续 2 日同目标（UPGRADE_CONFIRM_DAYS=2），降档当日生效，HYST_MARGIN=0.05 防震荡换手。

**旭创双确认**（`stock_confirm` 纯函数）：个股方向 = 0.5×趋势 + 0.5×动量 + 盘中/8（±0.25 封顶）；指数多/个股弱→-0.10 降档确认、指数空/个股强→+0.08 企稳、同向中性。实况验证：指数 +0.60（看多）× 旭创 -0.39（走弱）→ 综合 -0.09→-0.19，避免情绪背离时进场。

**回测口径（已收口，2026-08-28）**：信号日 d 使用截至 d-1 的最近完整收盘数据，仓位收益从 d+1 开始；严格全历史策略累计 +105.3%、年化 +6.2%、夏普 0.46、最大回撤 -42.1%，买入持有 +170.1%、最大回撤 -69.7%，平均仓位 44%，换仓 353 次。首轮 3 年训练/1 年测试、9 折 OOS 为策略 +64.6%、年化 +5.7%、夏普 0.41、最大回撤 -27.8%，买入持有 +111.2%；单次换仓成本 0.3% 时策略 +19.0%、年化 +2.0%、夏普 0.20、最大回撤 -38.3%。旧的 +291.9%/+188.8% 结果归档为宽松信息集或旧配置对照。
