## 四、核心诊断：为什么踩不到量化资金的点

万亿级量化资金（中性策略、指增、CTA、宏观对冲、套利盘）的决策**不基于「某公司发布了利好」**，而基于可程序化执行的**因子信号**：

| 因子类别 | 具体信号 | 系统现状 |
|---|---|---|
| 流动性/利率 | 日本加息、美债收益率异动、中美利差、央行逆回购/MLF/买断式逆回购 | ❌ 词表缺失，预筛分 0.14 丢弃 |
| 汇率 | 日元、离岸人民币、美元指数急变 | ❌ 词表缺失 |
| 波动率/对冲成本 | VIX、股指期货基差/贴水 | ❌ 词表缺失 |
| 资金流 | 北向、融资余额/两融、龙虎榜 | ⚠️ 部分有词，但被打分压制 |
| 个股 alpha | 新品发布、业绩、订单、政策补贴 | ✅ 权重最高（tech_cat 最高 +0.50） |

**根因（三重）**：
1. **词表缺口**：`HIGH_SIGNAL_KEYWORDS` 有「非农/美联储/加息」，但**无「日本央行/日元/套息/美债收益率/逆回购/MLF/离岸人民币/基差/贴水」**。8-13 的「日本央行加息」类资讯预筛分仅 0.14（门槛 0.55），被静默丢弃，根本没进 LLM。
2. **LLM prompt 误导**：「明确不推」条款把「日本央行委员意见」列为「外围央行日常表态」示例，LLM 会把「日本央行加息」这类**重大政策转向**误判为日常表态而拒推。
3. **结构性偏科**：科技词打分 +0.50 为单类最高，40 条候选上限被科技利好占满，宏观/流动性/汇率被持续挤压（此前 P2 已预警，本次实锤为「方向性」问题而非「容量」问题）。

## 五、调整方案（已实施）

### 5.1 `src/tools/keyword_tables.py` — HIGH_SIGNAL_KEYWORDS 补全（直通 LLM）

新增「全球流动性/套息/利率/汇率/资金面」因子词：`日本央行/日银/植田/日元/套息/套利交易`、`美债收益率/国债收益率/收益率曲线/利差/期限利差`、`逆回购/MLF/买断式逆回购/SLF/公开市场/社融/M2/信贷`、`离岸人民币/美元指数/人民币汇率/中间价`、`VIX/波动率/基差/贴水/融资余额/两融/融资融券`。这些词命中后仅**直通 LLM 判定**，最终是否推送仍由 LLM 把关，不会自动放行。

### 5.2 `src/tools/calculators.py` — HIGH_IMPACT_KEYWORDS 打分兜底

对上述因子词补打分（0.12–0.20），即使标题未命中高信号词直通，也能靠叠加过 0.55 门槛进入 LLM，形成第二道防线。

### 5.3 `scripts/real_time_push.py` — LLM prompt 优先级重排

- **新增优先级 1**：「全球流动性/利率/汇率/套息/资金面事件（驱动万亿量化资金系统性调仓的因子信号，market 级必推）」，明确列举日本央行/日元套息、美债收益率、人民币汇率、央行流动性操作、波动率与基差五类，并标注 8-13 实证漏推。
- **修正「外围央行日常表态不推」条款**：把「日本央行委员意见」从「日常表态」示例中移除，明确「日本央行加息/降息/YCC 调整及日元套息动向不属于日常表态，按优先级 1 必推」。

## 七、局限与后续建议

1. **数据源仍缺「行情因子」**：当前 8 新闻源是资讯文本，没有实时汇率/美债收益率/股指期货基差的量化数值。若要对「基差/贴水/波动率」做精确监控与阈值触发（而非仅靠标题关键词），需接入行情因子源（已连接的「通达信」MCP 提供 tdx_quotes / tdx_futures_quotes / wenda_macro_query，可评估接入）。
2. **「风险偏好收缩期」联动（进阶）**：当系统检测到日元急升/美债收益率飙升/VIX 急升等信号时，自动把科技利好类资讯降级为「风险收缩期」提示或降低其推送权重。此为第二阶段改造，需依赖行情因子源。
3. **候选容量再分配**：科技词 +0.50 打分仍偏高，若宏观/流动性资讯持续被科技挤占候选上限，可考虑对宏观因子类单独配额（此前 P2 建议，本次未改，避免与「防漏推」口径冲突）。
