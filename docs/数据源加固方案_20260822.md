# 数据源加固方案（2026-08-27 修订）

> 本项目只使用免费公开数据源，不接入、不保存、不读取需要鉴权的行情接口。
> 加固重点是免费多源回退、缓存新鲜度校验、字段兼容和数据健康度告警。

---

## 一、当前数据源与风险清单

| 中际旭创日线 | 新浪 akshare → 腾讯日K → 东财历史日线 | 中 | 各源末根按交易日校验；全部异常或过期时该确认维度降级，不阻断创业板核心信号 |
| 创业板50 TTM PE | 乐咕乐股 akshare | 中 | 获取失败时估值维度关闭，不用旧值伪造当日估值 |

## 二、免费数据源降级链

### 399006 核心日线

```text
新浪全量直连
  → 东财 akshare 历史接口
  → 东财 push2his 直连
  → 腾讯历史日 K
  → 新浪 akshare 末级接口
  → 本地缓存（仅当末根交易日仍新鲜）
```

新浪全量接口返回 `close` 和 `amount`，供核心趋势、量价和波动因子使用。
不同接口的成交量量纲可能不同，但量价因子只在同一来源窗口内计算比值；源切换时
不跨源拼接短期量能窗口。

### 300308 旭创确认日线

```text
新浪个股日线
  → 腾讯复权日K
  → 东财复权历史日线
  → 个股确认维度为空
```

回退源只在前一源为空、异常或末根交易日过期时请求；首个通过末根新鲜度校验的
结果直接返回，不额外请求后续接口。不同源的成交量/成交额字段只用于保持返回
结构，旭创确认实际使用收盘价计算趋势与动量，不跨源拼接历史窗口。

### 期货与资金流

```text
期货：新浪实时 → 中金所免费日行情 → 缺省
资金流：东财免费接口 → 缺省
```

期货新浪结果优先保留，中金所只补缺不覆盖。中金所某一日期请求异常时继续回看，
不会因单日网络错误提前结束。资金流不是核心历史信号，缺失时只关闭资金修正分量。

### 外盘与估值

```text
外盘：akshare 新浪封装 → Yahoo Chart → Stooq CSV → 单序列为空
估值：乐咕创业板50 TTM PE → 缺失时估值维度关闭
```

SOX、NDX、标普三个外盘序列分别尝试回退，不要求三个源同时成功；每次候选结果都
按最后一个交易日做新鲜度校验。Yahoo 可能返回限流，Stooq 可能返回浏览器验证页，
这些情况均视为失败，不能把 HTTP 200 或旧缓存当作有效行情。创业板50 PE 只保留
乐咕免费源，兼容中文/英文 TTM 字段别名，仅接受正数 PE；缺失值不进入滚动分位，
过期缓存和过期实时结果均降级为无估值增强。

## 三、缓存和时效规则

1. 缓存文件 TTL 只用于减少请求，不能单独证明数据新鲜。
2. 指数日线额外检查缓存最后一根 bar 的交易日期；免费接口全部失败且末根已过期时返回空表。
3. 核心历史数据为空或不足 62 根完整日线时主流程退出，不推送伪造信号。
4. 旭创、PE、外盘、资金流、期货等增强维度可以独立缺失，报告应标注或按 0 分处理。
5. 新鲜度按最近工作日窗口判断，拒绝未来日期；任何源切换都必须保持调用方所需字段结构，字段缺失只影响对应维度。

## 四、验证门槛

- 单元门禁：`python -m pytest tests/ -q -m "unit"`
- 免费链定向测试：覆盖成功、空响应、异常、缓存过期和降级顺序。
- 生产抽查：`python scripts/run_chinext_timing.py --dry-run`
- 策略改动必须同时提供回测数字和预测/影子验证证据；不能以单次 dry-run 代替回测。
- 数据源健康度任务应统计免费源连续失败次数，并在达到阈值时告警；告警不能改变核心信号的 fail-fast 规则。

## 五、已知限制与后续顺序

免费 HTTP 接口没有 SLA，可能出现限流、字段漂移、代理拦截和临时不可达。当前优先级：

1. 维护 399006 核心日线的多源回退和末根交易日校验；
2. 维护新浪/中金所期货补缺和东财资金流独立降级；
3. **已完成**免费源健康度连续失败告警：连续 3 轮失败触发一次，恢复后清零；`--collect` 允许告警，`--dry-run` 不改变状态；
4. **已完成外盘免费双源回退**：已覆盖 Yahoo/Stooq 解析、独立降级和缓存异常；
   但两个站点均无 SLA，当前网络抽查分别出现限流/浏览器验证，仍需依赖新浪封装、缓存
   和明确降级，不能宣称线上双源稳定可达；
5. 在数据链稳定后做择时系统样本外验证，不继续用同一段样本反复调参。

> 原则：先保证核心数据真实、可追溯，再使用增强维度；任何免费源不可用时，宁可
> 明确缺失或退出，也不使用无法证明时效的旧数据生成仓位信号。
