# 数据源加固方案（2026-08-22）

> 背景：全项目数据源 100% 为免费 HTTP 抓取（新浪/腾讯/东财/akshare 聚合），
> 东财 push2his 已被反爬（实证 RemoteDisconnected）。免费源对个人工具"够用但脆弱"，
> 本方案按关键性与成本给出加固路径，全部为**可选增强**（免费源保持为降级路径）。

## 二、加固优先级（按 性价比 × 关键性）

### P0：Tushare Pro（首要补充，成本≈0）

- **覆盖**：A 股日线/指数日线/指数 PE/资金流/期货数据，积分制（注册送积分，
  日线等基础数据免费积分足够个人日频使用）；
- **接入方式**：`data.py` / `factor_collector.py` 的加载函数改为
  `付费源优先 → 免费源降级` 双通道（约每函数 +10 行 try/except）；
- **收益**：399006 日线、旭创日线、PE 三个核心数据点从"免费抓取"升级为
  "带鉴权 token 的稳定接口"，且 Tushare 有明确 SLA 与限流文档；
- **成本**：注册免费；token 存环境变量（`TUSHARE_TOKEN`）。

### P1：基差/资金流（东财系被反爬的对冲）

> **状态：已实施**（SNA-02，2026-08-27，`scripts/factor_collector.py`）：
> 期货链 新浪实时（主链）→ 中金所官网（`futures_hist_daily_cffex`，成交量识别主力，
> 非交易日回看 3 日，仅 setdefault 补缺不覆盖新浪值）；
> 资金流链 东财（主链）→ Tushare `moneyflow_dc` 聚合（元→亿），退 `moneyflow`
> 大单+超大单合成（万元→亿），日频 T-1（快照标注 `main_net_source=tushare_t1`
> 区分当日盘中口径）；双链全失败 → 缺省降 0，永不无信号。Tushare 通道需 token（ND-002）。

- 期货基差替代：中金所官网每日结算数据（akshare `futures_cffex_*` 系）或
  Tushare 期货日线自算基差；
- 资金流替代：Tushare `moneyflow` 接口（两市主力净流入，日频足够修正层）。

### P2：外盘与估值

- 外盘：Stooq（免费 CSV，稳定）或雅虎财经（需代理）双源冗余；
- 估值：Tushare `index_dailybasic`（指数 PE/PB 日频）替代乐咕。

## 三、接入方式（统一抽象，不动业务层）

```python
# data.py 现有降级链的模式扩展为：
def _fetch_index_full_frame(symbol, start, end):
    # 1) Tushare（如配置）→ 2) 东财hist → 3) push2his直连 → 4) 腾讯 → 5) 新浪
    ...
# 所有 loader 保持返回同构 DataFrame，业务层零改动；
# 缺失时仍走原有"缺源降级"路径（永不无信号）。
```

要点：
1. **免费源永不删除**——付费源只是降级链头部；
2. token 缺失/过期 → 自动跳过付费源（`try/except` + 日志）；
3. 数据健康度监控已存在（factor_collector `sources` 键），可加"连续 N 轮付费源失败 → 推送告警"。
