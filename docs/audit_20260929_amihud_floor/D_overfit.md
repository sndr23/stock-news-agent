## A 与 C 的区分能力

A/C 只有 5 个仓位不一致日，整体累计收益分别 +178.65% 与 +177.65%，最大回撤相同。对配对日收益差使用 Newey–West lag 20 的近似检验：年化平均差 +0.044 个百分点，双侧 p=0.569；按该方差估计，观察到该效应的近似检验功效为 8.8%，80% 功效可检测的年化差约 0.218 个百分点。数值在 `evidence/A_vs_C_power.csv`。

功效估算依赖平稳性和 HAC 近似，只能说明这段日线代理数据难以区分如此微小的 A/C 差异，不能证明两种映射在任意未来行情下严格相等。组合子样本与分折胜负方向也不一致。综合来看，结果支持“当前样本的判别力不足”，不支持按单一回测排名择优改参数。验收：✅ O1–O5 均逐项输出，所有数值能在 `evidence/` 找到。
