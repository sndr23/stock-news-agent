# A｜成交量口径偏差与对称性

## 2026-09-29：全日与 14:46 快照

该日是唯一留存的盘中快照（`local_request_time`，14:46:13）；09-28 快照在 16:39 收盘后采集，与全日 bar 完全相同。09-29 数字如下，成交量单位均为 shares：

| 输入 | 全日 bar | 14:46 快照 | 快照减全日 |
|---|---:|---:|---:|
| close | 3142.563 | 3145.020 | +2.457 |
| amount | 12,905,890,864 | 11,803,505,700 | −1,102,385,164（全日的 −8.54%） |
| illiq | 0.000067568 | 0.000140175 | +107.46% |

以生产定义 `abs(close[t]/close[t-1]-1)/(amount[t]/1e9)` 计算 illiq。A 的 Amihud 因子由 +0.554 变为 +0.515（−0.039），核心分由 −0.550 变为 −0.555（−0.005）。固定当日已观测的非核心修正项 +0.070 后，总分从 −0.480 变为 −0.485（−0.005）。B 的因子/核心分变化为 −0.004/−0.002；C 为 −0.031/−0.004。完整原始行见 `evidence/caliber_snapshot_comparison.csv`。

单日排序从全日口径的 A=B>C 变为快照口径的 B>A>C。这个单日没有后续可比收益，因此不能据此声称策略排序翻转；但它证明真实盘中量价路径对三个映射的影响并非严格相同。

## 全样本 14:45 等效量代理

历史没有连续的 14:45 快照。为量化一项明确假设，做了两种按日统一缩放的量能代理：

- **活跃交易时长代理**：14:45 已交易 3.75 小时；按 9:30–11:30、13:00–15:00 的 4 小时连续交易时段均匀累计，乘数为 3.75/4 = 0.9375。
- **规格中的近似数值**：直接采用 0.922。规格写出的 `14.75/4.0` 算术结果是 3.6875，与约 0.922 不符；因此把 0.922 作为数值方案单独运行，没有把该算式当成推导依据。

两种代理都假设每天及历史窗口的成交量按同一常数比例变化，不模拟实际日内成交量曲线。结果中 A/B/C 各有 1,879 个核心分点完全相等、仓位路径完全相等；累计收益、夏普和 A/B/C 排名均无变化：A > C > B。0.9375 与 0.922 下，A/C/B 的累计收益分别仍为 +178.65% / +177.65% / +172.82%。数字与匹配计数见 `evidence/caliber_symmetry.csv`。

原因是 Amihud 先按滚动均值和标准差标准化：对整个成交量序列乘同一个常数，会把 illiq 同比例缩放，z 分数随之抵消。于是该均匀缩放代理在数学上不能检验非均匀的盘中成交分布影响。

## 判读

**在全样本统一缩放代理下，A/B/C 的排序没有改变；该结果是数据计算并可由 z 分数尺度不变性复现。** 但 09-29 实际快照显示 illiq 偏差 +107.46%，且单日 A/B/C 分数扰动不完全相同。只有一个盘中样本，无法证明真实 14:45 量能偏差在 2019–2026 每一天都对称。因此，本报告对历史策略排序给出完整日线代理结果；对真实盘中口径的长样本对称性结论降级为定性，不能把均匀缩放等同于真实快照回放。

证据：`evidence/caliber_snapshot_comparison.csv`、`evidence/caliber_symmetry.csv`、`evidence/snapshot_inputs.csv`、`evidence/run_audit_stdout.txt`。本节验收：✅ 两种口径和 A/B/C 排序均给出计算值；真实快照局限已披露。
