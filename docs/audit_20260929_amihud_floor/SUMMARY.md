# Amihud 地板效应审计｜第 2 轮摘要

## 最终四选一判定

**两者等价，判别力不足**——仅指预先声明的 A 基线与 C 去 clip，在当前完整日线代理样本上没有可辨认的稳定优势；这不是严格统计等价证明，也不表示真实 14:45 快照已得到充分验证。B 5/95 的累计收益低于 A，暂不支持替换基线。

**可信度：中（限完整日线相对比较）；真实盘中口径外推：低。** 1,878 个收益日、1,121 根预热日线、生产锚点全部重现，且 L2-L6 未发现前视；但历史只有一个 14:46 盘中对照日。A/C 仅 5 天仓位不同，年化平均收益差 +0.044 个百分点，HAC(20) 双侧 p=0.569，观察效应近似功效 8.8%，80% 功效的最小可检测年化差约 0.218 个百分点。

全日代理主结果：A +178.65% / 夏普 0.746 / 最大回撤 −32.34%；C +177.65% / 0.744 / −32.34%；B 5/95 +172.82% / 0.734 / −31.22%。三档均高于同期买入持有 +155.75%，且回撤更小。A 与 C 的胜负方向在子样本和分折间不稳定；触地板事件的 t 检验均未显著。

## 关键口径与锚点

- 09-28 全日与收盘后快照 core 均为 −0.770；09-29 全日为 −0.550，14:46 快照为 −0.555；四个锚点均在 ±0.005 内。
- 09-29 快照相对全日 close +2.457、成交量低 8.54%、illiq 高 107.46%；A 因子 +0.554→+0.515，core/总分各下降 0.005。
- 全样本将成交量统一乘 0.9375（按 14:45 已过 3.75/4 小时）或 0.922（规格给出的数值近似），三档核心分与仓位路径完全不变，A>C>B 排序不变。统一缩放会被 z 标准化抵消；它不能代替真实的日内成交分布。真实 09-29 快照的单日 A/B/C 分数扰动并不相同。
- 前视检查：L2 ✅、L3 ✅、L4 ✅、L5 ✅、L6 ✅（L6 限于未对原始指数做复权处理；provider 方法未单独验证）。L1 按规格作为披露项，不是致命门禁。

## 判定可能翻转的条件

若补齐跨多个市场阶段的真实 14:45 close/amount 快照，并在预先留出的区间中观察到 A 与 C 稳定的仓位/收益差，费用后差异超出当前约 0.218 个百分点年化的检测尺度，且邻域与分折结果一致，则应重做判定。若单边费用、换手或买入持有比较不再达标，也会改变策略建议。当前只有一天盘中快照，不能外推至完整历史。
