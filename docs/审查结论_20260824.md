## 三、需处理事项（按优先级）

### P0 — 撤销并清理明文 PAT

`scripts/_audit_repo.py` 第 2 行硬编码 GitHub PAT `ghp_kX3C...`（此处脱敏）。该文件未跟踪、未入历史，但**未被 .gitignore 覆盖**，一旦执行 `git add scripts/` 即会入库，公开仓库将立即泄露。

建议：

1. 立刻在 GitHub 上吊销该 PAT（Settings → Developer settings → Personal access tokens）。
2. 删除或重写 `scripts/_audit_repo.py`，改用 `os.getenv("GIST_TOKEN")`。
3. 将 `scripts/_audit_*.py` 等调试脚本移出根 `scripts` 或加入 `.gitignore`。

### P1 — 整理工作区

- 根目录 `scripts/` 残留大量 `_audit_*` / `_backtest_*` / `_study_*` / `_exp_*` 调试脚本（未跟踪），建议归档或删除。
- `docs/` 新增多个未跟踪规划文档（`status.md` / `roadmap.md` / `task-board.md` / `needs-decision.md` / `development-plan.md`），若为有效交付物应提交，避免长期悬空。

### P2 — 观察项（非缺陷）

- `.ENV` 的 OpenRouter Key / PushPlus Token / Gist PAT 仅存本地，符合当前设计；如本机多账号共用或担心丢失，可迁移到系统环境变量。
- `src/config.py` 的代理清除副作用、`src/llm_client.py` 的重试+熔断+JSON 容错，均为有意设计且有测试覆盖，无需改动。
- 创业板择时回测数字（+188.8%）README 已明确标注 in-sample 过拟合风险，解读审慎，无问题。
