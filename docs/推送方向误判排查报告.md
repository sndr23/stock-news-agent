## 三、根因分析（均经代码实证）

### 根因 1（主因）：降级路径的方向判定 = 对 title+content 全文做单遍关键词扫描

`_fallback_decision` → `predict_direction_by_rules(title, content)`：

```python
text = f"{title} {content}"           # 全文拼接
for kw in strong_bullish:             # 含 涨停/大涨/飙升/增持…
    if kw in text and not _has_negation(kw):
        return "bullish"              # 任意位置命中 → 整条判利好
```

**缺陷**：分类器不区分"事件主体"，正文中任何其他股票/板块的上涨词都会把整条利空新闻翻成利好。

**实证**（模拟今日两条利空新闻 + 真实风格正文）：

| 标题（利空） | 正文含 | 规则输出 |
|---|---|---|
| A股午评：科创50指数低开低走跌3.73%，算力硬件股集体回调 | 仅核电概念逆势活跃，利柏特涨停 | **bullish（强利好）❌** |
| 欧洲央行称伊朗战争重创欧元区消费，信心下滑拖累经济增长 | 能源价格大涨 | **bullish（强利好）❌** |

### 根因 2（次因）：`_normalize_direction` 别名子串匹配顺序缺陷（LLM 路径）

`alias_map` 中 `"涨"/"升"→bullish` 排在 `"跌"/"降"→bearish` **之前**，子串匹配"先命中先返回"：

```python
for key, mapped in alias_map.items():
    if key and key in raw:
        return mapped     # 含"涨"又含"跌"的字符串先命中"涨" → bullish
```

**实证**（等价复刻）：`"涨后回落"→bullish`、`"先涨后跌"→bullish`、`"利好兑现后回落"→bullish`（均应 mixed/bearish）。

### 根因 3（附带发现）：规则词表缺失 + 反向误判

- **词表缺失**：`跌超 / 走弱 / 走低 / 低开低走 / 回调 / 下滑 / 下跌 / 重创 / 监管问责 / 熔断` 均不在 strong_bearish → 降级时利空显示 **"中性"**（错但不至利好）。实测"韩国综指收盘跌超5%""一日8家券商遭监管问责"等均判 neutral。
- **反向误判**：`"马来西亚考虑放宽稀土出口管制以满足市场需求"` 命中 `"出口管制"` → 判 **bearish**（利好显示利空，实证）。

## 五、修复建议

| # | 修复项 | 方案 |
|---|---|---|
| 1 | **方向判定改为事件主体对齐**（治本） | 优先只用 `title` 判方向；正文仅在"事件句"（标题主体所在句）内扫描，正文中"其他板块个股涨跌"（"仅XX逆势大涨""XX涨停"）不参与事件方向 |
| 2 | **扩充规则词表** | strong_bearish 补：跌超/走弱/走低/低开低走/回调/下滑/下跌/重创/监管问责/熔断/负增长；strong_bullish 补：涨超/普涨/走高/上行/回升/涨价/上调目标价 |

| 4 | **"放宽/放松/解除/取消 + 利空词"反向修正** | 命中 `放宽|放松|解除|取消` 前缀时，利空词判定取反（修复"放宽出口管制→利空"反向误判） |

## 六、结论

**"利空显示利好"根因已锁定**：跳过 LLM 的降级路径中，`predict_direction_by_rules` 对标题+正文全文做单遍关键词扫描，利空新闻正文中任何"涨停/大涨"等词都会把整条判为强利好；`_normalize_direction` 的"涨"先于"跌"的子串匹配进一步放大了该风险。修复应优先落地第 1、3 项（方向与事件主体对齐 + 词表/顺序修正），并配套回归测试。
