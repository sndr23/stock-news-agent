一、结论先行

本质是两套系统，不是一个"量化程序"。① 事件驱动资讯推送——LLM 判定 + 三层去重 + 微信快讯，是软信号/信息流系统；② 创业板单资产择时——9 个注册因子（8 个有效）打分 + 仓位状态机 + 缠论 + 旭创双确认，是真正的量化内核。另有因子采集、信号回测、中信持仓日报、简报等辅助链路。
最强项是工程容错，而非 alpha。事件级指纹 + 同事件签名 13 分支（每个分支标注对应实证事故：恩智浦三推 / 索尼×台积电三推 / 日本央行加息三推 / 纳指三推）、Gist fail-stop 状态机、漏推保护链（挂起重试 ≤3 轮 / 候选溢出 pending / 300s 熔断 / 心跳告警）、CI 测试门禁——这套工程纪律显著优于同类个人项目。
最需审慎的是回测数字。当前严格信息集回测为策略累计 +105.3%、年化 +6.2%、夏普 0.46、最大回撤 -42.1%；买入持有 +170.1%、最大回撤 -69.7%。首轮 walk-forward OOS 为策略 +64.6%、年化 +5.7%、夏普 0.41、最大回撤 -27.8%，买入持有 +111.2%；计入单次换仓成本 0.3% 后，OOS 为 +19.0%、年化 +2.0%、夏普 0.20、最大回撤 -38.3%。当前证据支持回撤改善，不支持跑赢买入持有或存在稳定 alpha。旧口径仅作历史对照。
信任基石仍空缺。signal_backtest 是设计中的可信度底座，但 dir 字段 2026-08-19 才上线——当前 64 条已推事件可评估 0 条（冷启动），资讯信号"是否有效"暂时无法量化，与"先验证、再优化"纪律存在张力。
当前工程风险集中在状态并发、外部调度和免费源可用性：Gist 读-改-写仍非原子（高）· 外部定时服务与 Actions 最近实际运行记录尚未核验（中）· 数据源全部为免费 HTTP 抓取，东财、Yahoo/Stooq 已有反爬或限流实证（中低）。基金轮动入口、capped 语义和修正层分项封顶问题已修复，不再列为当前故障。
