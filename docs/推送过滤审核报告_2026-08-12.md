## 二、CPI 漏推根因（证据链）

**对照组是决定性证据**：同为美国重磅宏观数据，"非农"在词表中、预筛直通；"CPI"不在词表、预筛拦截。同一重要度等级的宏观数据，处理路径完全不同。

### 2.3 词表缺口清单

- `HIGH_SIGNAL_KEYWORDS`（预筛直通）：有"美联储/鲍威尔/欧央行/非农/汇率/降准/降息/加息"，**缺 CPI、PPI、通胀、物价、利率决议**。
- `HIGH_IMPACT_KEYWORDS`（预筛打分）：有"美联储 0.15/加息 0.12/降息 0.12"，**缺 CPI 等**。
- `POLICY_KEYWORDS` / `MEDIUM_KEYWORDS`：同样无 CPI/通胀/物价。

### 2.4 次要根因：LLM prompt 定位模糊

少数命中"油价""美联储"进 LLM 的 CPI 衍生报道（通胀降温、加息压注）最终也未推（seen 无标记，即非强档方向或 push=false 分支）。LLM prompt 优先级 1 列举了"宏观政策、央行、证监会"，但**未明确把"美国重要宏观数据发布（CPI/非农/利率决议）"列为必推**；而"明确不推"区域里"外围央行日常表态"等措辞可能让 LLM 倾向不推外国宏观数据。非农能推是因为词表直通 + 实际被 LLM 判过，CPI 则完全没机会。

## 五、修复建议（按优先级）

### P0 — 补全宏观数据词表（本次 CPI 漏推的直接根因）

1. `HIGH_SIGNAL_KEYWORDS` 海外央行与宏观区增加：`CPI`、`PPI`、`通胀`、`物价`、`利率决议`、`FOMC`、`美债`、`就业数据`、`失业率`（与"非农"同级别）。
2. `HIGH_IMPACT_KEYWORDS` 增加：`CPI 0.20`、`PPI 0.18`、`通胀 0.15`、`物价 0.12`（确保即使不进直通也能过 0.55 门槛的兜底——注意"通胀"词还出现在"芯片通胀"等语境，需评估误伤）。
3. 预筛后处理增强：**对命中"美国/中国 XX 数据公布"的数据类快讯，即使未过 0.55 也应至少送 LLM 判定**（数据发布是确定性事件，规则可直接放行至 LLM，由 LLM 判断重要性）。

### P1 — LLM prompt 补充宏观数据必推条款

在优先级 1 明确加入："**美国/中国核心宏观数据发布（CPI、PPI、非农、GDP、利率决议、PMI）及其市场反应**——market 级，必推"；同时在"明确不推"里把"外围央行日常表态"限定为"不含数据发布本身"。

### P1 — 噪声词表补漏

`_NOISE_COLUMN_MARKERS` 增加 `新闻汇总`（现有"新闻精选"不覆盖"新闻汇总"），并在**推送前**对已判定条目做二次校验（本轮"欧盘美盘重要新闻汇总"即由此漏网）。

### P2 — 缓解科技偏科

- 同事件 48h 窗口内同题材推送计数上限（如当日同板块推送 ≥4 条后仅保留 scope=market/sector 级，个股行情类不再放行）。
- 候选分层：宏观/地缘/政策类（命中宏观词表）与科技类分开配额，避免 40 条上限被科技独占。

### P2 — 审核自动化

将本报告的审计脚本固化为定期任务（每日收盘后拉取 Gist 快照，扫描"重大关键词未推送"与"同题材推送超限"，输出日报）。
